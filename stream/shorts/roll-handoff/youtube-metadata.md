# Title

20 Milliseconds Turned This Robot Duck’s Crash Into a Landing

# Description

Microduck could complete the roll—but one control step decided whether it
recovered or kept tumbling. At a 0.84-second handoff, one evaluation failed.
Moving the transition 20 milliseconds earlier produced three clean recoveries
from three perturbed starting poses.

The official Pollen Robotics roulade policy remains frozen. The learned part is
only the high-level handoff time from rolling to standing.

Code and reproducible results:
